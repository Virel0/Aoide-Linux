# Porting tracker

Every feature of the Electron desktop app (Aoide 1.17.3), and where it stands
in the Rust app. Built from a read of the Electron code on 2026-10-24.

**Status:** ⬜ not started · 🟨 in progress · ✅ done · — not porting

**Round:** **1** core listening (the first usable release) · **2** next · **3** later

**Server (2026-10-30):** the app plays from [Melete](https://github.com/Virel0/Melete),
which replaced Jellyfin and serves Aoide's sync routes (`/aoide/*`) itself.
`aoide-melete` is the client; `aoide-sidecar` talks to the `/aoide/*` routes on
the same server and token. Jellyfin-only features are marked — below. Rows the
move touched are 🟨 until clicked through in the app against a real Melete:
`cargo test -p aoide-melete --test live` and `cargo test -p aoide-sidecar live`
run against one when `MELETE_TEST_URL`, `MELETE_TEST_USER` and
`MELETE_TEST_PASSWORD` name a throwaway server.

## Open questions

Not settled yet:

- **The release key**: signing is built (`packaging/sign.sh`, in the
  release jobs only); it needs a release key made and stored as the
  `AOIDE_SIGNING_KEY` secret, and its public half committed, as
  `docs/releases.md` says. Until then releases carry SHA256SUMS files and go
  out unsigned.
- iced 0.14 limits: no keyboard focus on buttons and tiles (only text
  fields are focusable; Ctrl+K reaches everything, Settings' categories
  included), and no screen-reader tree (no accessibility layer in 0.14).
- **When this app replaces the Electron one**: once it has been used on
  Linux desktops for a while.
